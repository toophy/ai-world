# Frontier Colony (Three.js)

一个单场景网页模拟经营原型，参考 RimWorld 的基础交互：

- 2 个小人自动任务派发与自主移动
- 5 种基础地形（草地、泥地、沙地、水域、山地）
- 山地矿物开采（1 种矿）
- 1 种植物（浆果灌木），可种植与采收
- 支持手动下达：移动、建造、种植、采集、采矿、徒手攻击
- 较完整 UI（资源条、殖民者面板、检视器、任务队列、日志、底部命令栏）

## 运行

在仓库根目录执行：

```bash
python3 -m http.server 4173
```

浏览器打开：

- http://localhost:4173/web-rimworld/
